# Что ещё поправить в `src`

Повторный проход после первого рефакторинга. Старые замечания (общий storage, `DEV_LEVELS`, `RootLayout`, `Field`, цвета уровней, хуки) в коде уже закрыты. Ниже только то, что всё ещё ведёт себя неправильно. В файлах стоят комментарии «Здесь можно…», номера строк — номера этих комментариев.

## `src/pages/UsersPage.tsx`

| Строка | Что изменить |
| --- | --- |
| 1 | Убрать лишние два пробела в начале каждой строки. Файл целиком сдвинут вправо. |
| 41 | Не вызывать `trim()` на каждый символ и не записывать поиск в URL сразу. Поле контролируется уже обрезанным `search`, поэтому пробел между словами стирается и запрос из двух слов («James React») набрать нельзя. Обрезку оставить в `filterUsers`. |
| 105 | Не прятать блок с `ref={loadMoreRef}`, когда фильтр ничего не нашёл, и не искать только среди уже загруженных страниц. Если на первой десятке совпадений нет, sentinel не монтируется и следующие страницы не запрашиваются. Поиск лучше отдать в API либо догружать страницы, пока есть `nextSkip`. |
