## О проекте

RecruitMe помогает работодателям находить IT-специалистов, а разработчикам — рассказывать о себе. В каталоге можно просматривать профили кандидатов, создавать резюме и общаться прямо внутри приложения.

## Возможности

- 👥 **Каталог специалистов** — просмотр профилей разработчиков и поиск подходящих кандидатов
- 🧑‍💻 **Профиль специалиста** — подробная информация о пользователе и его навыках
- 📝 **Создание резюме** — форма с опытом, навыками и профессиональными целями
- 📄 **Мои резюме** — список созданных резюме
- ✉️ **Сообщения** — список диалогов и переход к переписке
- 💬 **Чат** — страница общения с выбранным пользователем
- ⚡ **Быстрая навигация** — маршрутизация без перезагрузки страницы
- 📱 **Адаптивный интерфейс** — корректная работа на мобильных устройствах и десктопах

## Установка и запуск

### Требования

- [Node.js](https://nodejs.org/) 20 или новее
- npm

### Шаги

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/MelKon96/RecruitMe.git
   cd RecruitMe
   ```

2. **Установите зависимости**

   ```bash
   npm install
   ```

3. **Запустите в режиме разработки**

   ```bash
   npm run dev
   ```

   Vite выведет в терминале локальный адрес приложения (обычно `http://localhost:5173`).

## Доступные команды

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск сервера разработки |
| `npm run lint` | Проверка кода с помощью ESLint |
| `npm run build` | Сборка production-версии |
| `npm run preview` | Локальный просмотр production-сборки |
