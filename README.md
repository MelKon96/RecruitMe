SPA-платформа для подбора разработчиков, созданная для практики современного стека и строгой типизации.

## 🛠️ Стек

- **React 19 & TypeScript**
- **TanStack Router**
- **TanStack Query**
- **Tailwind CSS v4**
- **Vite**
- **WebSocket**
- **DummyJSON API**

## 📌 О проекте

Приложение позволяет искать разработчиков, фильтровать их по навыкам и грейдам (Junior, Middle, Senior, Lead), просматривать подробные профили и общаться в чате в реальном времени.
